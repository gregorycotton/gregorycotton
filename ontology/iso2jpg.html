Rust CLI tool for old photo/image discs and other ISO containers. It scans the filesystem inside a `.iso`, finds files with matching extensions, copies them to a normal folder, and uses ImageMagick to convert extracted non-JPEG images to `.jpg`.


Repository can be found on GitHub.


Sample ISO files available at archive.org.


Sample converted JPGs on are.na.
