weBG is a browser-side, one-click background remover for JPEG, PNG, and WebP images. It is currently in desktop beta and is intended for simple use cases such as an image editor where a user chooses one photo and clicks Remove background. The library returns a transparent PNG Blob or an explicit error.

weBG was built for my own purposes and as such is limited/specific to my use case, as things stand.
