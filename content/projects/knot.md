<p>Knot is my client-server TUI for running LLMs locally. It allows me to install models to run locally,
                    search/retrieve past conversations, swap models, load files into chat context (and more) from within
                    my terminal. As its a tool I actively use, I'm making frequent (ish) changes to it to suit my needs;
                    you can see what I've been working on in the <a class="primary-link" target="_blank" href="https://github.com/gregorycotton/knot">Knot GitHub repo</a>.</p>
