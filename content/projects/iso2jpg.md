<p>Rust CLI tool for old photo/image discs and other ISO containers. It scans the filesystem inside a `.iso`, finds files with matching extensions, copies them to a normal folder, and uses ImageMagick to convert extracted non-JPEG images to `.jpg`.</p>

<br>

<p>Repository can be found on <a href="https://github.com/gregorycotton/iso2jpg" target="_blank">GitHub</a>.</p>

<br>

<p>Sample ISO files available at <a href="https://archive.org/details/Corel_Professional_Photos_Collection_1994" target="_blank">archive.org</a>.</p>

<br>

<p>Sample converted JPGs on <a href="https://www.are.na/gregory-cotton/corel-professional-photos-collection" target="_blank">are.na</a>.</p>
